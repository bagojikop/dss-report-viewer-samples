01 / LIBRARY & REPORT CODE

Use Dss.Reporting.Symbols

The NuGet package is Bagojikop.Dss.Reporting.Symbols; the DLL, namespace, and report assembly reference are Dss.Reporting.Symbols. The .NET Standard 2.0 library returns image bytes: GenerateQRCode produces PNG; GenerateBarcode produces Code128 BMP.

In a .NET host, deploy the Symbols DLL and the resolved dependencies, including QRCoder and zxing. Microsoft Report Builder does not install NuGet packages itself. The ASP.NET Core reporting package already includes Symbols as a dependency.

  1. Open the downloaded GuideDemo.rdl in Report Builder. It already contains the assembly reference and wrappers.
  2. Right-click outside the report border and choose Report Properties. Inspect References when available in your version. The existing reference is Dss.Reporting.Symbols; static methods do not need class-instance entries.
  3. For a new report, add the assembly reference in SSDT Report Designer, or add the CodeModules fragment to the RDL with an XML editor. Then reopen the file in Report Builder.
  4. Open Report Properties > Code and add the wrappers below.
Report Builder preview and DSS preview are different.

Microsoft documents limits on custom assemblies in standalone Report Builder, including local preview. Use an RDL prepared with SSDT or the supplied reference, and test in DSS. For SSRS or a separate RDLC host, deploy and configure the assembly and dependencies for that host and verify compatibility. These screenshots demonstrate authoring, not a successful Microsoft-host rendering test. Microsoft custom-code guidance.

DSS recognizes these supported Code wrapper names natively; it does not execute arbitrary report VB code. Power BI paginated reports do not support custom assemblies.

02 / QR CODE

Add a QR image

  1. Choose Insert > Image and place the image on the report.
  2. Open Image Properties > General, set the source to Database, and click fx beside the image value.
  3. Enter the expression below and set MIME type to image/png.
  4. Under Size, choose proportional fitting and use a square image area. Save the report and preview it in DSS.

Use a dataset field

Inside a tablix row, use its current field. For a body image outside a data region, use an aggregate with the actual dataset name.

GenerateQRCode encodes the exact supplied text. StringToQR first converts UTF-8 text to Base64, then encodes that Base64 text. Use StringToQR only when the consumer expects that payload.

03 / CODE128 BARCODE

Add a barcode image

Insert another image. In Image Properties, choose Database, set the Value to the expression below, and set MIME type to image/bmp. Use a wide image area, keep its aspect ratio, and leave the generated quiet margins visible.

Blank inputs return an empty byte array. DSS treats them as absent images; other report hosts may need a visibility expression for optional images.

04 / GO TO REPORT

Open a detail report

  1. Create the target report first. The demo target is GuideDetails.rdl, with a String report parameter named InvoiceId.
  2. In GuideDemo.rdl, right-click the Open invoice report textbox and choose Text Box Properties > Action.
  3. Select Go to report. Set Specify a report to GuideDetails.
  4. Under report parameters, click Add. Set Name to InvoiceId and Value to the source report parameter expression below.
  5. Save both reports under the same folder and open the source in DssReportTabsComponent.

In DSS, GuideDetails resolves beside docs/GuideDemo.rdl and becomes docs/GuideDetails.rdl. A leading slash resolves from ReportRoot. Deploy the target template and map its datasets if it has any. The static demo has no datasets, so it needs no query-map entries.

The tabs wrapper opens the target in a new viewer tab. With a standalone DssReportViewerComponent, handle reportAction yourself. An SSRS server has its own deployment and navigation rules. Microsoft action instructions.

05 / GO TO URL

Open an Angular form

  1. Right-click Open invoice form and choose Text Box Properties > Action.
  2. Select Go to URL and click fx beside Select URL.
  3. Enter this expression, click OK, and save.
  4. Register the matching internal form route in your Angular host, as shown below.

The Angular host provides the form. Report Builder only stores the URL expression in the RDL. The DSS viewer opens matching internal routes as a modal when urlActionRoutes is configured. You can instead handle urlAction with your own dialog service. External HTTP(S) links are emitted to the host; the built-in modal handles registered internal routes.

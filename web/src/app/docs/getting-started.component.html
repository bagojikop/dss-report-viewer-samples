Create an ASP.NET Core API

Replace MyReportApi/Program.cs with the following. CORS lets the Angular app call your API during development.

2

Add reports and dummy data

Merge these settings into your API's appsettings.json. All report paths are relative to ReportRoot.

Copy the three report-tab templates and their fictional dataset, then start the API.

3

Install the Angular viewer package

The viewer is installed from npm. Library implementation source is not part of this sample.

4

Create your Angular web app

Create the web app beside the API and install the published viewer package.

Replace my-report-web/src/main.ts with this minimal working viewer. HttpClient is registered once at bootstrap.

In src/styles.css, add body { margin: 0; }. Run npm.cmd start, then open http://localhost:4200. Select an invoice to open its details in a new report tab.

}
03 / VERIFY

Check the connection

Your API should list available report templates. If a report is missing, check the template folder and filename before adding viewer features.

When a preview does not load: check that port 5000 is available, the API is running, CORS permits your web origin, and each report dataset has a matching JSON mapping. Include template and data files when deploying the API.

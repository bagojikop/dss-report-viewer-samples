Enable the Send control

Import the viewer and register HttpClient in your Angular host. Load apiUrl from aa.config.json, and enable showSend. showHeader exposes the account/settings icon while configuring. These inputs also work on dss-report-tabs.

04 / API & ADAPTER

What the API receives

POST to /api/reports/send/docs/GuideDemo.rdl, replacing the relative report path for your report. These are documentation examples; viewing this page makes no send request.

The request model includes apiEndpoint, but the controller uses the connection details saved in Share Settings. A browser request cannot override the saved endpoint, authorization, or SMTP credentials.

What your delivery adapter receives

Your adapter must decode the attachment and translate this payload for your provider. A successful response means acceptance, not confirmed recipient delivery. Check provider status before retrying after a timeout.

05 / COMMON SETTINGS

Persistence and troubleshooting

Settings are encrypted in Data/share-settings.protected by default. Preserve data-protection keys when moving the API. GET responses redact secrets; blank secret fields retain saved values. Protect settings and delivery endpoints with your application's authentication and authorization.

  • Send missing: check showSend, server sharing enabled, and the share-settings GET response.
  • Delivery unavailable: verify the {{page.section}} configuration and saved credentials.
  • Unexpected draft: check the configured endpoint and, for email, smtpEnabled.
  • Provider error: inspect API logs and confirm your adapter accepts the attachment contract.

Common Settings contains the complete Share Documents reference, API endpoints, and key-persistence setup.
